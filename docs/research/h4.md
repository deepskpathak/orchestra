## A confound: prompt caching across runs

Per-run cost here ($0.62 to $0.74) is about a quarter of the earlier bench runs ($2.15 on 2026-11-25, about $2.90 in the first H2 pilot). The model was the same (`claude-opus-5-5` for the planner and judge). The difference is the 1-hour prompt cache:

- The first H2 pilot's planner, run on its own, wrote 104,651 cache tokens and read 9,889, costing $0.93.
- An H4 planner, run straight after other bench runs, wrote 6,065 cache tokens and read 199,834, costing $0.12.

Bench runs share the harness prompts, so back-to-back runs read a warm cache. A run's cost therefore depends on what ran just before it, not only on its arm. Both H4 arms ran warm (all of `h4-base`, then all of `h4-cost`), so the comparison holds roughly, but cache discipline, the thing `h4-cost` turns on, is partly what the warm cache already gives both arms. A cleaner H4 would interleave the arms per goal and repeat, and record cache-write and cache-read tokens per row.

## Deviations

- Spend was far below the estimate because of the warm cache. No stop rule was reached.
- No goals, arms or bars changed after the run started.
